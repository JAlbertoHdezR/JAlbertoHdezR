## 📌 Sobre mí
<img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Hand%20gestures/Waving%20Hand.png" height="20px" width="20px"> ¡Hola! Soy José Alberto

Soy **Desarrollador Backend** y me gusta el mundo del **Software**, especialmente todo lo que ocurre detrás de una aplicación.

Mi principal interés está en el **Backend con Java y Spring Boot**. Disfruto entender cómo funcionan las cosas, trabajar con datos, construir APIs y, sobre todo, **resolver problemas mediante software**.

🧠 Me gusta aprender entendiendo el **porqué de las cosas**, no solamente hacer que el código funcione.

🛠️ Disfruto enfrentar problemas, investigar diferentes soluciones y encontrar una forma clara y práctica de resolverlos.

📚 Actualmente sigo aprendiendo y mejorando mis conocimientos en **Java, Spring Boot, buenas prácticas de desarrollo y arquitectura de software**.

💡 Para mí, programar es una combinación de lógica, aprendizaje y curiosidad. Cada problema es una oportunidad para aprender algo nuevo y mejorar la forma en que hago las cosas.

🚀 Mi objetivo es seguir creciendo como **desarrollador Backend**, participar en proyectos reales y continuar construyendo software cada vez mejor.

🤝 También me gusta conectar con otros desarrolladores, compartir conocimientos y aprender de las experiencias de quienes están recorriendo un camino similar.
